# NFC Gift Cards

Create Lightning Network gift cards backed by LNURL-withdraw links and write them directly to inexpensive NFC tags (NTAG213/215/216) using the browser's Web NFC API.

## Features

- Create fixed-amount Lightning gift cards
- Generate LNURL-withdraw links automatically
- Display QR codes for every gift card
- Copy LNURL to clipboard
- Write LNURL directly to NFC tags via Web NFC
- Track redemption status
- Manage expiry dates

## Supported NFC Tags

- NTAG213
- NTAG215
- NTAG216

## Requirements

- Chrome on Android (for NFC writing)
- Withdraw extension enabled

## Usage

1. Enable the extension
2. Select a wallet
3. Enter amount, number of uses, and optional note
4. Click "Create Gift Card"
5. Scan the QR code or write to an NFC tag
